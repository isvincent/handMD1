# 2-2 岩溶作用與岩溶地形

[TOC]

濕潤地區的**石灰岩、石膏、岩鹽**等**可溶性岩層**，常因岩溶作用而形成特殊景觀，其中以**石灰岩地形**最常見。

## 一、岩溶作用

```mermaid
flowchart LR
    A["雨水、河水、地下水<br/>溶入二氧化碳或有機酸"] --> B["成為酸性溶液"]
    B --> C["流動時接觸石灰岩"]
    C --> D["碳酸鈣被溶解帶走<br/>＝岩溶作用（侵蝕）"]
    D --> E["溶於水中的碳酸鈣<br/>在適當環境下沉澱<br/>＝堆積地形"]
```

**發達條件**：
- **高溫多雨**的氣候
- **裂隙豐富**的石灰岩層

---

## 二、岩溶地形（喀斯特地形）

石灰岩的岩溶地形可分為**地表**與**洞穴**兩類。

### （一）地表岩溶地形：依侵蝕程度排序

岩溶作用沿著地表岩層的破裂面進行，地形隨時間逐步演變：

```mermaid
flowchart LR
    A["滲穴<br/>地表的漏斗狀凹洞"] --> B["窪盆<br/>持續溶蝕、擴大"]
    B --> C["溶蝕盆地<br/>數個窪盆串連"]
    C --> D["錐丘<br/>盆地間殘留的高聳岩體"]
    D --> E["殘丘<br/>岩層幾乎溶蝕殆盡<br/>只剩緩起伏小丘"]
```

| 地形 | 特徵 | 例子 |
|---|---|---|
| **滲穴** | 最初發育的凹洞 | 澳大利亞**甘比爾山** |
| **窪盆** | 滲穴持續溶蝕擴大 | 中國**廣西** |
| **溶蝕盆地** | 數個窪盆串連成盆地 | 中國**貴州** |
| **錐丘** | 盆地之間殘留的高聳岩體 | 中國貴州、廣西（桂林山水） |
| **殘丘** | 地表只剩緩起伏的小丘 | 菲律賓**保和島**（巧克力山） |

**人地關係**：岩溶區的風化物質**貧瘠**，農地多集中在：
- 溶蝕盆地內地勢低平處，例如貴州興義的「**壩子**」
- 錐丘與殘丘之間的河谷平原

**等高線判讀**：滲穴、窪盆呈**封閉的凹陷等高線**（常以短齒線標示朝向低處）；錐丘則是一圈圈密集的封閉等高線、頂部標有高程點。

### （二）洞穴岩溶地形

#### 1. 侵蝕：石灰岩洞穴與伏流
- 地下水長期溶蝕石灰岩 → 地下形成**石灰岩洞穴**。
- 地表河水因岩溶作用往下滲漏、潛入地下 → **伏流**。
  - 例：中美洲**馬雅人**在石灰岩洞穴中取用的水源就是伏流。

#### 2. 堆積：鐘乳石、石筍、石柱

岩溶過程中，碳酸鈣溶於水，形成含**碳酸氫鈣**的液體。液體進入洞穴後：
- 溫度、壓力改變 → **二氧化碳被釋放** → 碳酸鈣結晶析出；或
- 水分**蒸發** → 碳酸鈣重新沉澱

| 地形 | 位置 | 形成 |
|---|---|---|
| **鐘乳石** | 從洞頂往下長 | 洞頂滴水處沉積 |
| **石筍** | 從地面往上長 | 滴落地面處沉積 |
| **石柱** | 連通上下 | 鐘乳石與石筍相連 |

- 例：斯洛維尼亞**波斯托伊納洞穴**（喀斯特地區）——景觀奇特，多作為**觀光資源**。

## 📰 標弟來報報：石灰岩洞穴探險——失蹤受困 18 天

:::info
**事件經過（2018 年，泰國）**
- **地點**：泰國北部清萊府的**睡美人洞**（Tham Luang Nang Non），是泰國第四大的地下石灰岩洞穴，也是知名的神祕景點。
- **起因**：6 月底，一支少年足球隊的 12 名隊員和 1 名教練進洞探險，未依時出洞。
- **困境**：適逢**雨季**，地表雨水迅速灌入地下洞穴，洞內較低窪處被淹沒，隊員受困。洞穴全長約 4 公里，有約四成以上的路段積水，必須潛水或游泳。
- **救援**：救難單位日夜抽水，水位稍降後深入洞穴找到 13 人；讓受困者穿戴潛水裝備與全罩式面罩，由**潛水員前後護送**，沿事先布置的繩索穿越黑暗、曲折的水道。
- **結果**：歷經 **18 天**，13 人全數獲救。
:::

**🤔 想一想**
1. 為什麼雨季時進入石灰岩洞穴特別危險？
2. 從地形系統的角度，說明降雨如何快速改變洞穴內的環境。

:::spoiler 💡 思考方向
石灰岩區裂隙、滲穴、伏流發達，地表水能**快速下滲**並灌入地下洞穴；洞穴內低窪處會迅速積水，切斷出路。這是「投入（降水）改變 → 作用過程（地下逕流）改變 → 環境快速變化」的例子。
:::

## ✅ 隨堂小測

1. 岩溶作用的關鍵化學物質是什麼？在什麼環境下最發達？
2. 依序寫出地表岩溶地形的演育順序。
3. 鐘乳石和石筍的差別？

:::spoiler 💡 參考答案
1. 溶有二氧化碳（或有機酸）的酸性水溶解碳酸鈣；高溫多雨、裂隙豐富的石灰岩區。
2. 滲穴 → 窪盆 → 溶蝕盆地（間有錐丘）→ 殘丘。
3. 鐘乳石由洞頂向下沉積；石筍由地面向上沉積；兩者相連成石柱。
:::
